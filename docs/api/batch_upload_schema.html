create

POST /projects/{projectId}/schemas

Operation ID: upload-schemas-for-project.

Authentication: basic token (ServiceAccount).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | projectId | path | integer | Yes | Your project id (eg: 12345) |

Request body

application/json

Property Type Required Description
entries array of object Yes The list of schema entries to upload
entries[].entityType enum: event, profile Yes
entries[].name string Yes The entity name (eg: Added To Cart)
entries[].schemaJson object Yes The schema for the entity
entries[].schemaJson.description string No The entity description
entries[].schemaJson.metadata object No
entries[].schemaJson.metadata.com.mixpanel object No Metadata about this entity that is specific to Mixpanel
entries[].schemaJson.metadata.com.mixpanel.$source string No The source of this schema. Used by partners to identify themselves
entries[].schemaJson.metadata.com.mixpanel.contacts array of string No A list of emails belonging to users responsible for this entity.
entries[].schemaJson.metadata.com.mixpanel.displayName string No If set, this name will be used in the Mixpanel UI instead of the entity name
entries[].schemaJson.metadata.com.mixpanel.dropped boolean No [Events only] If true, the event will be dropped at ingestion time.
entries[].schemaJson.metadata.com.mixpanel.hidden boolean No If true, this entity will be hidden in the Mixpanel UI
entries[].schemaJson.metadata.com.mixpanel.tags array of string No A list of tags to associate to this entity that can be used in the Mixpanel UI for filtering
entries[].schemaJson.metadata.com.mixpanel.teamContacts array of string No A list of team names responsible for this entity.
entries[].schemaJson.properties object No The list of properties that should be included on an instance of this entity
truncate boolean No If true, delete your entire data dictionary before inserting these entries. This is primarily useful if you want to upload a single file that represents your entire data dictionary.
